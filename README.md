# DESCRIZIONE DEL PROGETTO 

Realizzazione di un progetto riguardante il mondo del gaming, in cui è possibile visionare una vastissima gamma di giochi per tutte le console. 
Effettuando la registrazione/login al sito è possibile aggiungere ogni singolo gioco ai propri preferiti, leggere e lasciare recensioni.

E’ possibile ricercare i giochi per genere, per piattaforma, cercarli direttamente per nome attraverso una barra di ricerca nella navbar, oppure visionare solo quelli del 2024.
 
Per gli utenti registrati sarà inoltre possibile modificare il proprio nome, cognome, username e avatar attraverso la pagina del proprio profilo, oltre che avere una panoramica delle recensioni lasciate e dei giochi aggiunti ai preferiti. 


I dati riguardate i giochi sono stati forniti da RAWG API (https://rawg.io/apidocs ).


*Il tutto è stato realizzato utilizzando come stack tecnologico:*
- React Js per la creazione di un sito Single Page Application, dinamico e veloce anche grazie alla gestione del routing della libreria "React Router-DOM".
- Tailwind CSS come framework di stile.
- daisyUI come libreria di componenti Tailwind.
 - Supabase e PostgreSQL come Database.
